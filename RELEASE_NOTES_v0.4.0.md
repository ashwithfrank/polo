## Polo v0.4.0

The biggest update so far: more tools, search, trash and a grid view.

### New
- **Images to PDF**: combine images into one PDF, reorder pages, choose A4 or fit-to-image
- **Zip and unzip**: compress files and folders, extract `.zip` files
- **Duplicate finder**: find identical files and move the extra copies to trash
- **Trash**: deleted files can be restored for 30 days, with Undo after deleting
- **Search**: find any file or folder by name, with filters
- **Categories**: tap Images, Videos, Audio, Documents, Archives or Apps to see everything of that type
- **Grid view** for Browse, with picture previews
- **Image thumbnails** in file lists
- **File details**: type, location, size and dates
- **Settings**: saved sort order, hidden files and list/grid choice, plus an About screen

### Install
Download `app-release.apk` below and open it on your Android phone. You may need to allow installs from this source. Polo asks for All files access the first time you open it.

### Known limits
- Internal storage only (no SD card or USB drive yet)
- ZIP only (no RAR or 7z); password-protected zips can't be opened
- Image converter outputs PNG and JPG
